# 🌟 RUMI (Reflect Understand Maintain Improve)

A full-stack web application designed to help you build better habits, track your mood, and reward your consistent progress. 

Built with **Spring Boot** using an **MVC** architecture, CommitMates combines a clean, responsive interface with a robust backend to keep you accountable and motivated on your self-improvement journey.

## ✨ Features

* **🎯 Dynamic Habit Tracking:** Build and monitor your daily routines. Features a real-time habit tracking timer powered by asynchronous JavaScript and RESTful endpoints.
* **📝 Journaling & Mood Tracking:** Reflect on your day with an integrated journaling system that seamlessly logs your mood alongside your daily habits.
* **🏆 Reward System:** Stay motivated! Earn rewards and visualize your progress as you successfully complete tasks and maintain your habit streaks.
* **🧠 Smart Nudge Notifications:** A custom algorithm that provides context-aware dashboard reminders based on your recent activity logs to keep you on track.

## 🛠️ Tech Stack

* **Backend:** Java, Spring Boot, Spring Data JPA
* **Frontend:** Thymeleaf templates, HTML5, CSS3 (Grid & Flexbox), Vanilla JavaScript
* **Architecture:** Model-View-Controller (MVC)
* **Workflow:** Agile Software Development Life Cycle (SDLC)
